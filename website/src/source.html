Use the source checkout.

Inspect Labs is being prepared for an open source release. A public repository address has not been configured for this preview.

The framework and three plugins can be installed from the source checkout. Start with the quickstart, then read the environment authoring guide.

What is being prepared

  • MIT licensed framework source and upstream attribution.
  • Installed-package controls and evidence replay.
  • Documentation, examples and this framework website.

A source release does not establish scientific validity or physical readiness. The pinned robot dependency currently makes this a source distribution rather than a PyPI release.

The repository URL, deployment and public manuscript version are final publication decisions.
