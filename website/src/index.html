Why laboratory evaluation

Safeguards that prevent misuse in practice.

Model capabilities in biology are accelerating rapidly over time, and scientific AI agents with access to biological tools and lab equipment are becoming increasingly integrated into physical R&D workflows. Ensuring that safeguards reliably prevent misuse in practice is an urgent R&D challenge.

Litmus prepares for a future of autonomous science by continuously testing and strengthening safeguards at critical AIxBio infrastructure chokepoints in real world deployments to build better defenses. Our immediate priority is AI enabled biological misuse. We will work directly with labs and providers to turn findings into improved safeguards, defenses, and evidence based demonstrations for policymakers, strengthening defenses in depth against engineered pandemics.

A laboratory layer for Inspect AI

Keep the evaluation native.
Connect the laboratory.

Inspect Labs connects the agent's actions to observations from the systems that carry out the work. Follow the path from task to outcome.

01 / Evaluate

Inspect AI runs the task.

A researcher defines the task and agent in Inspect AI. Its models, tools, approvals, limits, scoring and logs remain the evaluation substrate.

02 / Connect

Inspect Labs connects the laboratory.

Scoped tools let the agent request work. The environment checks requirements before dispatch and records the request and safeguard decision.

03 / Observe

The system records what happened.

Services and instrument stacks retain execution. For robot policies, Inspect Robots runs the trial and keeps its native record. Inspect Labs links those observations to the task.

04 / Judge

Score the observed outcome.

Compare the agent's report with independent records. If the records are missing, the outcome stays unknown. A completed evaluation can be rescored without submitting new actions.

Start with a working control

Install. Run. Inspect.

Run a deterministic liquid-handling control first. Then use the same native task with a model or agent of your choice.

From the source checkout · Python 3.12+ 
git clone https://github.com/litmus-labs/inspect-labs.git
cd inspect-labs
uv venv --no-project --python 3.12 .venv
uv pip install --python .venv/bin/python '.[pylabrobot,openai]'
source .venv/bin/activate
inspect eval inspect_labs/serial_dilution --model mockllm/model -T scripted=true
inspect view

No credentials needed.

This control exercises task execution, simulated liquid handling and scoring. It establishes software mechanics, not model performance or scientific validity.
