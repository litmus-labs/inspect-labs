Why laboratory evaluation

Test safeguards where scientific work happens.

Scientific AI agents can use biological tools, request laboratory services and direct robotic work. Safeguards need to prevent disallowed work while allowing legitimate research.

Our first mission is biological misuse prevention. We are building a shared foundation for researchers and providers to evaluate capabilities, test defenses and verify improvements across these workflows.

A laboratory layer for Inspect AI

Keep the evaluation native.
Connect the laboratory.

Inspect AI runs the task.

Use its models, agents, tools, approvals, limits, scoring and logs. Inspect Labs evaluations are normal Inspect tasks.

Inspect Labs binds the environment.

Expose scoped laboratory tools, check declared requirements before dispatch and collect observations for judging outcomes.

Lab systems execute the work.

Instrument stacks and services retain execution. Inspect Robots runs robot policies and keeps their native trial records.

Start with a working control

Install. Run. Inspect.

Run a deterministic liquid-handling control first. Then use the same native task with a model or agent of your choice.

From the source checkout · Python 3.12+ 
uv venv --no-project --python 3.12 .venv
uv pip install --python .venv/bin/python '.[pylabrobot,openai]'
source .venv/bin/activate
inspect eval inspect_labs/serial_dilution --model mockllm/model -T scripted=true
inspect view

No credentials needed.

This control exercises task execution, simulated liquid handling and scoring. It establishes software mechanics, not model performance or scientific validity.

Prototype environments

Start digital. Extend into physical laboratories.

The current connections are building blocks for research environments. Meaningful studies also need domain-reviewed tasks, controls and valid outcome measures.

Current environment connections and validation limits
Connection What you can evaluate Current evidence
Liquid handling Dilution and transfer tasks with deck, volume and reagent observations. PyLabRobot simulation and Opentrons simulator controls.
Measurement services Whether a submitted job completed and the report matches its result. Queued service fixtures and synthetic plate-reader QC.
Screening review Review a screening result and check the independent disposition. Common Mechanism plugin mechanics. Full-reference runtime verification remains pending.
Robot tasks Connect native policy trials and their metrics to laboratory evaluations. Inspect Robots bridge and deterministic software controls. No physical validation or RFM study.
